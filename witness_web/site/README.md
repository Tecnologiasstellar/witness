# Witness web

The home of the Witness iPhone app: an art-first landing page with real app screenshots, the full 30-card archive with every plate, a generalized world map of every card's range, a link to Field Notes, a public method, and Privacy, Terms, and Contact pages. Next.js App Router, prerendered, deployed with the Vercel CLI.

## Run and verify

```bash
npm install
npm run dev
npm run lint
npx tsc --noEmit
npx next build --webpack
```

Next.js App Router, React, TypeScript, and Tailwind v4. Every route prerenders; the only client JavaScript beyond what Next ships is Vercel Analytics and two components: the how-it-works observer, and the live map on `/map` (MapLibre GL over OpenFreeMap tiles, loaded only there, with its worker copied to `public/maplibre/` by `prebuild`; the server-rendered SVG is the map without it). Plates are plain `<img>` WebP files under `public/images/plates/`, generated by `../../tools/export_web_plates.sh` from the app's asset catalog.

## Source of truth

- `../PUBLIC_CLAIMS_SOURCE_OF_TRUTH.md` controls public wording.
- `data/species.json` is the assembled mirror of the 30 individual `WitnessCore` catalog records (`python3 tools/export_catalog.py`).
- `data/letter-transcript.txt` is the narrated text of the free Field Season opening letter, stripped from its SSML by the export script.
- `../docs/COMPETITION_AND_RELEASE_GATES.md` controls production and release claims.
- `../docs/DECISIONS.md` controls accepted project and media-rights decisions.
- `../docs/ACCESS_AND_COMMERCE_SOURCE_OF_RECORD.md` describes proposed commerce. It is not purchase evidence.

## Routes

```text
/                     Hero, how it works (real screenshots), archive band, the works, FAQ, download CTA
/archive              30 cards as a plate grid
/archive/[id]         One card in the app's own order: plate, stats, five plates, story, act, sources
/map                  Every card's generalized range on one world map, with the organizations each card cites (Spanish at /es/map)
/method               How a card is made
/privacy              What the site and the app collect (matches the App Store label)
/terms                Plain terms, including purchases
/contact              Email, corrections, Instagram

/witnesses[/id] and /support redirect permanently to /archive[/id] and /contact; /field-notes* redirects to community.witnessatlas.com.
```

## Asset provenance

All 151 plates are WebP derivatives of approved catalog assets (D-013), produced by `../../tools/export_web_plates.sh`. App screenshots under `public/images/app/` are simulator captures of the shipped build with the status bar cropped. The site labels illustrations as original and never as documentary photography.

## Deployment boundary

Vercel root directory: `witness_web/site`. Framework: Next.js. No environment variables or secrets are required. Since 2026-09-16 the project is connected to GitHub: a push to `main` is the deploy (about a minute; `vercel.json` skips the build for commits that do not touch this folder), and `vercel deploy` from this directory no longer works, by design, so nothing can ship from the wrong tree. After a push that adds or changes URLs, `python3 ../../tools/notes.py ping --main` pushes the sitemap to IndexNow — this site has no ship routine, so nothing submits it otherwise.
