# Species backlog

Last updated: 2026-08-22. Editorial backlog for card production (D-014, D-019).

**Every fact in this file is unverified working notes.** Status abbreviations are commonly reported classifications (CR critically endangered, EN endangered, VU vulnerable, EW extinct in the wild, EX extinct, PE possibly extinct) and must be independently re-verified against primary sources at carding time — never copied into a production card from this list. Ordering within tiers is a suggestion, not a queue.
